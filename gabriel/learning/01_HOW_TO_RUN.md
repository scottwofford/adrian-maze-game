# How to run Gabriel's game / Cómo correr el juego de Gabriel

**The easy way / La forma fácil:**
https://scottwofford.github.io/adrian-maze-game/gabriel/

**On your own computer / En tu computadora:**

```bash
cd ~/build/adrian-maze-game
python3 -m http.server 8090
```
Then open / Luego abre: http://localhost:8090/gabriel/
