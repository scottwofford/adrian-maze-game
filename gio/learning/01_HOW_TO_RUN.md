# How to run Gio's game / Cómo correr el juego de Gio

1. Open the Terminal / Abre la Terminal
2. Go to the repo folder / Ve a la carpeta del repo:
   ```bash
   cd ~/build/adrian-maze-game
   ```
3. Start the little web server / Prende el servidor:
   ```bash
   python3 -m http.server 8090
   ```
4. Open in the browser / Abre en el navegador:
   http://localhost:8090/gio/

Press **Cmd+Shift+R** to reload if you do not see your changes.
